# Конфликт при слиянии

Где: при выполнении git merge feature/discount в ветку main.

Причина: ветки feature/pricing и feature/discount изменили одну и ту же
строку цены товара «Кружка» в файле catalog.md (450 против 400).

Решение: вручную выбрал итоговый вариант — 400 (скидка), удалил маркеры
конфликта <<<<<<<, =======, >>>>>>> и зафиксировал отдельным коммитом
"fix: разрешить конфликт цены кружки в catalog.md".
